Query 6 - JOIN
================================================================================
SQL:
SELECT b.title, b.price_gbp, b.price_inr, b.rating,
               b.in_stock, c.category_name
        FROM books AS b
        INNER JOIN categories AS c
            ON b.category_id = c.category_id
        ORDER BY b.rating DESC, b.title
        LIMIT 10;
