# Zepto Data & AI Platform Capstone

This repository contains the capstone project for the Certificate Program in Artificial Intelligence and Machine Learning.

## Modules

### 1. Data Engineering Pipeline

Located in:

`/data_pipeline`

### 2. Analytics Pipeline

Located in:

`/analytics`

### 3. GenAI Support Assistant

Located in:

`/support_assistant`

The support assistant implements an offline-first RAG system using Sentence Transformers, ChromaDB, LangGraph, Pydantic, FastAPI, and Docker.
